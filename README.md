## Итоговая практическая работа по Теме 1 (ПР №4 и ПР №5): «Какой знак видит камера?»

Итоговое занятие Темы 1 «Глубокое обучение» курса «Искусственный интеллект» для 10 класса. Сначала – практическая методология по главе 11 книги Гудфеллоу: как выбрать метрику, быстро собрать базовую модель, поставить диагноз по ошибкам на обучающей и валидационной выборках, перебирать гиперпараметры и отлаживать сеть. Затем ученики проходят полный цикл на новой задаче из беспилотного транспорта: по кадру камеры 32 × 32 определяют один из восьми дорожных знаков. Нужно найти и исправить проблемы в данных, честно разделить выборку, проверить конвейер, обучить базовую сверточную сеть, улучшить ее приемами Блока 2 в пределах бюджета опытов с журналом, один раз проверить итоговую модель на тестовой выборке и написать отчет. Защита работы засчитывается как промежуточный контроль по Теме 1.

## Теория (презентация)

1. **Порядок работы.** Четыре шага по Гудфеллоу: цель и метрика, базовая система как можно раньше, диагноз, изменения по одному. Точность, F-мера с макроусреднением и полнота опасного класса; пример Street View с покрытием. Базовая модель по умолчанию и ориентир «самый частый класс». Диагноз по двум ошибкам: недообучение, переобучение, утечка, ошибка в коде. Когда собирать больше данных.
2. **Гиперпараметры.** Скорость обучения как главный гиперпараметр и U-образная кривая ошибки. Как гиперпараметры меняют емкость. Поиск на сетке и случайный поиск, логарифмическая шкала. Разброс между зернами: разница меньше шума не доказывает улучшение.
3. **Отладка.** Шесть приемов отладки по Гудфеллоу и проверка начальных потерь ln K. Утечка через похожие примеры и разбиение по группам. Журнал опытов.
4. **Итоговая работа.** Задача и данные, предупреждение о ловушках, десять шагов за два часа, готовые функции, критерии оценивания, формат защиты, чек-лист на любой проект.

## Практическая работа

Классы: «Стоп», «Уступи дорогу», «Главная дорога», «Пешеходный переход», «Движение налево», «Движение направо», «Въезд запрещен», «Ограничение скорости». В варианте около 1850 цветных кадров 32 × 32 из 220 проездов (серий кадров одного знака при приближении) и около 850 тестовых кадров из 100 других проездов. У каждого ученика свой вариант; номер указывается в первой ячейке ноутбука. Сеть, цикл обучения, рисунки и журнал опытов даны готовыми, все решения и код шагов ученик пишет сам.

| Часть | Шаг | Что делаем |
| --- | --- | --- |
| ПР №4 | 1 | первый взгляд: кадры, проезды и доли классов, рисунки кадров |
| | 2 | поиск испорченных кадров по статистикам яркости, очистка |
| | 3 | разбиение по проездам со стратификацией, сравнение со случайным разбиением, нормализация по обучающей части |
| | 4 | ориентир, начальные потери ln 8, переобучение 64 кадров |
| | 5 | базовая сеть, цена неверного разбиения, кривые, матрица ошибок, диагноз |
| ПР №5 | 6 | аугментация (сдвиг, яркость, контраст) и опыт с горизонтальным отражением |
| | 7 | случайный поиск гиперпараметров, повтор лучшего опыта с другим зерном; по желанию ResNet-18 с весами ImageNet |
| | 8 | вес ошибки на классе «Стоп», выбор итоговой модели |
| | 9 | однократная проверка на тестовой выборке, опасные ошибки, голосование по проезду |
| | 10 | отчет с журналом опытов |

Каждая практическая работа оценивается из 10 баллов, критерии приведены в начале ноутбука. В ПР №5 бюджет – не больше 8 обучений.

Задания повышенной сложности: дообучение предобученной ResNet-18, аугментация при проверке, отказ от ответа при низкой уверенности, кривая обучения по числу проездов, карта перекрытия для ошибок «Стоп» → «Въезд запрещен».

## Требования

Python 3.9 или новее, `torch`, `numpy`, `pandas`, `matplotlib`, `scikit-learn`. Интернет не нужен. Для необязательного опыта с предобученной сетью нужны `torchvision` и файл весов `resnet18-f37072fd.pth` из занятия «Трансферное обучение» в папке `weights` рядом с ноутбуком. Опыт из 20 эпох базовой сети занимает на процессоре около минуты.
